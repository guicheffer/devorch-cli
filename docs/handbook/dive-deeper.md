## Playbook by Discipline

Each part of the value stream can improve its own inner loop ([AI Transformation Strategy for HelloTech](https://docs.google.com/document/d/1jWz5ppZVQGQZDvKfYZSvKSfCY20tuzizczj8ZojTOEA/edit?tab=t.0#heading=h.twa41vpl7h46)); we describe playbooks for each role below:

* [UX Playbook (⭐☆☆)]()  
* [Engineering Playbook (⭐⭐☆)]()  
* [Engineering Manager Playbook (⭐☆☆)]()

Each playbook follows the following structure:

1. **Objective**: What is their objective in this Value Stream.  
2. **Key tools and services**: How to get onboarded to key tools and services.  
3. **Expected outcome**: The important part of the value stream is what is the expected handover, or artifact generated by this role.  
4. **Example workflows**: There’s not one way to Rome; we’ll list several ways to execute in each playbook as well, and this part is open to contributions.
