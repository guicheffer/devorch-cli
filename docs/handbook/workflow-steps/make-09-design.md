# 9. Design

**Cycle:** MAKE (1 Sprint)
**Phase:** Creation

## Purpose

Create detailed design artifacts that translate UX specs into visual and interactive designs ready for development. Design is AI-first and component-based.

## AI-Native Approach

Use AI to:
- Generate design variations
- Create component libraries
- Ensure accessibility and consistency
- Produce design system documentation

## Key Activities

- Create high-fidelity mockups
- Design component interactions
- Ensure design system compliance
- Validate accessibility
- Prepare Figma handoff

## Inputs

- UX Spec
- Product Spec
- Design system
- Brand guidelines
- User flows

## Outputs

- **High-fidelity designs**: Pixel-perfect mockups
- **Component specifications**: Design tokens, spacing, etc.
- **Interaction details**: Animations, transitions
- **Accessibility annotations**: ARIA labels, keyboard nav
- **Figma file**: Organized and ready for dev handoff

## Common Pitfalls

- Designing in isolation from specs
- Not using the design system
- Forgetting accessibility considerations
- Designs that are technically infeasible
- Poor handoff documentation

## Success Criteria

- [ ] Designs match UX and Product specs
- [ ] Design system is followed
- [ ] Accessibility is considered
- [ ] Components are reusable
- [ ] Handoff is clear for engineering
