# 4. Prototype

**Cycle:** THINK (Non-Linear)
**Phase:** Validation

## Purpose

Create a functional prototype to visualize the solution and gather early feedback. Prove value before committing to full development.

## AI-Native Approach

Use AI to rapidly build prototypes:
- Generate UI mockups and interactions
- Create functional code prototypes
- Simulate data and workflows
- Build testable experiences quickly

## Key Activities

- Define prototype scope
- Build functional prototype
- Prepare for testing
- Document assumptions

## Inputs

- Preferred solution direction
- Research insights
- Technical constraints
- Design principles

## Outputs

- **Functional prototype**: Working demonstration
- **Testing plan**: How to validate with users
- **Key assumptions**: What the prototype tests
- **Feedback collection approach**: How to gather learnings

## Common Pitfalls

- Making the prototype too polished (wastes time)
- Building without a clear hypothesis to test
- Not planning how to collect feedback
- Prototype scope creep

## Success Criteria

- [ ] Prototype is functional and testable
- [ ] Scope is minimal but sufficient
- [ ] Testing approach is defined
- [ ] Prototype validates key assumptions
- [ ] Built in 1-2 hours (not days)
