# Learn

**Cycle:** CHECK (Bridge between THINK and MAKE)
**Phase:** Reflection

## Purpose

Capture learnings from both THINK and MAKE cycles to build organizational intelligence. Every cycle should make the next cycle smarter and faster.

## AI-Native Approach

Use AI to:
- Synthesize learnings across projects
- Identify patterns and trends
- Build searchable knowledge bases
- Generate insights from retrospectives

## Key Activities

- Document what worked and what didn't
- Capture patterns and anti-patterns
- Update process documentation
- Share learnings across teams
- Build institutional knowledge

## Inputs

- Project outcomes
- Retrospective insights
- User feedback
- Performance metrics
- Team reflections

## Outputs

- **Learning documents**: Captured insights
- **Updated playbooks**: Improved guidance
- **Pattern library**: Reusable solutions
- **Knowledge base updates**: Searchable context

## Common Pitfalls

- Not making time for reflection
- Documenting learnings but not applying them
- Blame culture preventing honest reflection
- Learning in silos (not sharing across teams)
- Not making learnings searchable/actionable

## Success Criteria

- [ ] Learnings are captured from every cycle
- [ ] Knowledge is shared across teams
- [ ] Patterns are documented and reusable
- [ ] Playbooks are continuously improved
- [ ] Future cycles benefit from past learnings
