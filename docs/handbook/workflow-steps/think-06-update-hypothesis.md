# 6. Update Hypothesis

**Cycle:** THINK (Non-Linear)
**Phase:** Iteration

## Purpose

Refine or pivot the hypothesis based on validation learnings. Decide whether to continue iterating in THINK or move to the MAKE cycle.

## AI-Native Approach

Use AI to:
- Synthesize learnings across iterations
- Identify patterns in feedback
- Generate refined hypotheses
- Assess readiness for MAKE cycle

## Key Activities

- Review validation results
- Update hypothesis statement
- Refine success criteria
- Decide: iterate or proceed to MAKE
- Document learnings

## Inputs

- Validation results
- User feedback
- Original hypothesis
- Business objectives

## Outputs

- **Updated hypothesis**: Refined based on learnings
- **Go/no-go decision**: Continue to MAKE or iterate
- **Key learnings**: What we discovered
- **Prioritization input**: For opportunity backlog

## Common Pitfalls

- Moving to MAKE too early (insufficient validation)
- Iterating too long (analysis paralysis)
- Not documenting why the hypothesis changed
- Losing sight of the original problem

## Success Criteria

- [ ] Hypothesis has been updated based on learnings
- [ ] Clear decision made: iterate or proceed
- [ ] Learnings are documented
- [ ] If proceeding: hypothesis is ready for MAKE cycle
- [ ] If iterating: clear plan for next iteration
