# 5. Validate

**Cycle:** THINK (Non-Linear)
**Phase:** Testing

## Purpose

Test the prototype with real users and stakeholders to validate assumptions and gather feedback. Learn what works and what doesn't before full development.

## AI-Native Approach

Use AI to:
- Analyze user feedback at scale
- Identify patterns in responses
- Synthesize qualitative feedback
- Generate insights from test sessions

## Key Activities

- Conduct user testing sessions
- Gather stakeholder feedback
- Collect data and observations
- Synthesize findings
- Identify what to change

## Inputs

- Functional prototype
- Testing plan
- Target users
- Key questions to answer

## Outputs

- **Validation results**: What worked, what didn't
- **User insights**: Key learnings
- **Next actions**: Continue, pivot, or iterate
- **Updated hypothesis**: Refined based on feedback

## Common Pitfalls

- Testing with the wrong users
- Leading questions that bias feedback
- Not enough test sessions
- Ignoring negative feedback
- Not documenting learnings

## Success Criteria

- [ ] Prototype tested with real users
- [ ] Feedback has been collected and synthesized
- [ ] Clear decision on next steps
- [ ] Key learnings are documented
- [ ] Hypothesis has been validated or needs refinement
