### PHASE 1: Collect Figma Input [INTERACTIVE]

Ask the user for the Figma design URL.

The URL should look like: `https://www.figma.com/design/FILE_KEY/Design-Name?node-id=123-456`

**Important:** Ensure the user selects a **specific frame**, not the entire file. A full file will have too much content for effective analysis.

If the URL lacks a `node-id` parameter, ask the user to select a specific frame in Figma and copy that link.
