### PHASE 2: Extract Design

Use the `figma-dev-mode-figma-researcher` skill to extract design information:

1. Get file metadata to understand structure
2. Extract design tokens:
   - Colors (fills, strokes)
   - Spacing (padding, margins, gaps)
   - Typography (font family, size, weight, line height)
   - Border radii
   - Shadows/effects
3. Extract component structure and hierarchy
4. Get 1-2 targeted screenshots for visual reference
