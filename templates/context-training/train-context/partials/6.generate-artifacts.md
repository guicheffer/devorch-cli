**What the subagent will do:**
- Create directory structure: `devorch/context-training/{name}/` with subdirectories `implementers/` and `verifiers/`
- Generate specification.md with patterns for spec writers (API, data modeling, UI specs)
- Generate implementation.md with architectural patterns and file organization guidance
- Generate one implementer file per domain:
  - implementers/ui.md (UI component patterns)
  - implementers/state.md (state management patterns)
  - implementers/api.md (API integration patterns)
  - implementers/testing.md (testing patterns)
  - implementers/styling.md (styling patterns)
  - etc. for each discovered domain
- Generate verifier files for testing domains (verifiers/ui.md, verifiers/api.md, etc.)
- Validate all required files are present
- Return generation summary
