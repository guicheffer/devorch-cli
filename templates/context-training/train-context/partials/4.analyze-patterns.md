Launch the **context-training/pr-pattern-analyzer** subagent using the Task tool to analyze patterns from the selected PRs and assess tech stack coverage.

**Task tool parameters:**
```markdown
- subagent_type: "context-training/pr-pattern-analyzer"
- description: "Analyze patterns from merged PRs"
- prompt: "Analyze the PR list from Step 3 and compare against the tech stack from Step 2.

Tech Stack Analysis (from Step 2):
$TECH_STACK_JSON

PR List (from Step 3):
$PR_LIST_JSON

Your job is to:
1. Parse the tech stack JSON to understand what technologies should exist
2. Parse the PR list JSON to get PR numbers to analyze
3. Fetch full PR details using gh CLI (work in memory - do not write temporary files)
4. Analyze code patterns from diffs and file contents
5. Extract concrete code examples
6. Track which tech stack items are observed in actual PR code vs. not observed

Return JSON with:
- Pattern analysis organized by technical domain
- Tech stack coverage report (observed vs not-observed technologies)
- Concrete code examples from PRs
- Pattern frequency/prevalence

Focus on objective pattern extraction - do not make recommendations yet."
```

**What the subagent will do:**
- Read devorch/tech-stack.md to establish baseline expectations
- Fetch complete PR details using `gh pr view` and `gh pr diff` (keep data in memory)
- Analyze patterns across all files: components, state, APIs, testing, styling, file organization, imports
- Compare found patterns against tech stack to identify:
  - ✅ **Observed**: Technologies found in actual PR code
  - ❌ **Not Observed**: Technologies in tech stack but not found in PRs
- Calculate pattern frequency and domain prevalence
- **Return structured JSON in its final response message (NOT written to disk)**

**After the subagent completes:**

**IMPORTANT: The subagent returns the COMPLETE pattern analysis JSON in the Task tool result. Parse the entire JSON from the Task tool response.**
