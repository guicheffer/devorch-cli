Launch the **context-training/pattern-reviewer** subagent using the Task tool:

```markdown
Task tool parameters:
- subagent_type: "context-training/pattern-reviewer"
- description: "Interactive pattern review with user"
- prompt: "Present the pattern analysis from Step 4 to the user for interactive review.

Pattern Analysis JSON (from Step 4):
$PATTERN_ANALYSIS_JSON

You will receive structured pattern analysis with discovered patterns organized by domain. Your job is to:
1. Present a high-level summary of all discovered domains and pattern counts
2. Review each domain interactively, showing patterns with concrete code examples
3. For each domain, ask user to validate, reject, or refine patterns using AskUserQuestion
4. Ask about pattern priorities (Critical/Important/Recommended)
5. Ask if user wants to add missing patterns not discovered by analysis
6. Collect skill references to include in context training
7. Ask for context training name
8. Return refined and validated pattern set ready for artifact generation

Be collaborative - this is about understanding what patterns matter to this team. Present patterns domain by domain (not all at once). Show actual code examples from PRs for every pattern. Use AskUserQuestion extensively for structured feedback.

Don't skip any domains, even if they have few patterns. Don't make decisions for the user - always get explicit approval."
```

**What the subagent will do:**
- Present discovered domains with pattern counts (e.g., "UI Components - 23 PRs (92%) - 8 patterns found")
- For each domain:
  - Show all patterns with descriptions, examples, and frequency
  - Use AskUserQuestion to let user select which patterns to include (multiSelect: true)
  - Ask about priority level (Critical/Important/Recommended)
  - Ask if user wants to add missing patterns
  - If yes, collect additional patterns from user input
- Ask about skill references to include (based on libraries used)
- Ask for context training name
- Return validated patterns with user preferences including:
  - Approved patterns per domain
  - Priority levels per domain
  - User-added patterns
  - Skill references to include
  - Context training name
  - Summary statistics
