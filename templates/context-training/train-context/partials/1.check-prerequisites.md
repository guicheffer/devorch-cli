Before continiuing context training we need to verify the following requirements:

1. Required CLI tools
2. `devorch/tech-stack.md`
3. Context training location at `devorch/context-training`

### Requirement 1: Check Required Tools

Verify that required command-line tools are installed:

Check `gh` CLI:

```bash
if ! command -v gh &> /dev/null; then
  echo "❌ GitHub CLI (gh) not found"
  echo "Install: https://cli.github.com/"
  exit 1
fi
```

Check `jq` command:

```bash
if ! command -v jq &> /dev/null; then
  echo "❌ jq not found"
  echo "Install: https://jqlang.github.io/jq/download/"
  exit 1
fi
```

Check `gh` is properly authenticated:

```bash
if ! gh auth status &> /dev/null; then
  echo "❌ GitHub CLI not authenticated"
  echo "Run: gh auth login"
  exit 1
fi
```

### Requirement 2: `devorch/tech-stack.md` exists

Look for `devorch/tech-stack.md` in the project root:

```bash
# Check if file exists
[ ! -e "devorch/tech-stack" ] && echo "Does not exist"
```

### Requirement 3: Verify devorch Directory

Ensure the `devorch/context-training` directory exists for storing context training:

```bash
# Check directory exists
[ ! -d "devorch/context-training" ] && echo "Directory does not exist"
```

## Report missing requirements

If any of the requirements are missing **STOP** and report missing requirements. Don't continue the process.

### Fixing `Requirement 1`:

Explain the user how to install `gh` and `jq` with `brew`. If not authenticated, tell them they need to authenticate with `gh auth login`.

### Fixing `Requirement 2`:

Explain the user they need to run `/analyze-tech-stack` command to create the tech stack artifacts before running this command.

### Fixing `Requirement 3`:

**ALWAYS auto-create this directory** without asking. Run:

```bash
mkdir -p devorch/context-training
```

Then tell the user you created it.
